# rust-clan-bot

Discord-бот клана по Rust: ежедневная проверка онлайна в BattleMetrics, статусы «инактив» и «АФК» кнопками, список «кто должен играть».

## Как работает
- Игрок жмёт кнопку «Мой профиль» и заполняет: Steam ID, ссылку на BattleMetrics, регион, карту для выплат. Данные записываются в Google-таблицу через небольшой скрипт Apps Script (`apps_script.gs`): вкладка «Профили», одна строка на игрока, повторная отправка обновляет строку.
- Раз в сутки (REPORT_TIME_UTC) бот проверяет каждого из таблицы в два шага. Шаг 1: время в голосовых каналах Дискорда. Набрал норму (8 ч), значит всё в порядке. Шаг 2: если в гс меньше нормы, бот смотрит часы в Rust в BattleMetrics. Если и там меньше нормы, игрок попадает в сводку (карта в сводку не попадает).
- Команды для админов (право «Управлять сервером»): `/panel` выкладывает кнопку, `/report` запускает проверку сразу.
- Токен BattleMetrics необязателен.
- Учёт гс лежит в `data.json` на сервере (в git не попадает).

## Подключение таблицы
1. В таблице: Расширения, Apps Script, вставить содержимое `apps_script.gs`, заменить `ПОМЕНЯЙ_СЕКРЕТ` на свой секрет.
2. Развернуть, Новое развертывание, тип «Веб-приложение», выполнять от своего имени, доступ «Все». Скопировать адрес веб-приложения.
3. На сервере: `bash /opt/rust-clan-bot/setup.sh` спросит токен бота, ID канала, адрес веб-приложения и секрет, сам запишет `.env` и перезапустит бота.

## Секреты
Лежат только в `.env` на сервере (в репозиторий не попадают). Шаблон: `.env.example`.

## Деплой на сервер
Первичная установка: `bash install.sh`
Автообновление: таймер `rust-bot-update` раз в минуту проверяет GitHub и при новых коммитах сам обновляет и перезапускает бота.
Принудительно вручную: `bash update.sh`
Логи бота: `journalctl -u rust-bot -f`
Логи автообновления: `journalctl -u rust-bot-update -f`
