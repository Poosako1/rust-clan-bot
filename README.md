# rust-clan-bot

Discord-бот клана по Rust: ежедневная проверка онлайна в BattleMetrics, статусы «инактив» и «АФК» кнопками, список «кто должен играть».

## Как работает
- Игрок жмёт кнопку «Мой профиль» и заполняет: Steam ID, ссылку на BattleMetrics, регион, карту для выплат.
- Раз в сутки (REPORT_TIME_UTC) бот проверяет каждого в два шага. Шаг 1: время в голосовых каналах Дискорда. Набрал норму (8 ч), значит всё в порядке. Шаг 2: если в гс меньше нормы, бот смотрит часы в Rust в BattleMetrics. Если и там меньше нормы, игрок попадает в сводку.
- Команды для админов (право «Управлять сервером»): `/panel` выкладывает кнопку, `/report` запускает проверку сразу, `/card @игрок` показывает карту (видно только вызвавшему).
- Номера карт хранятся зашифрованными (Fernet). Ключ в `secret.key` рядом с ботом, в git не попадает. Потеряешь ключ, карты не расшифровать. CVV и срок бот не запрашивает.
- Токен BattleMetrics необязателен.
- Профили и учёт гс лежат в `data.json` на сервере (в git не попадает).

## Секреты
Лежат только в `.env` на сервере (в репозиторий не попадают). Шаблон: `.env.example`.

## Деплой на сервер
Первичная установка: `bash install.sh`
Автообновление: таймер `rust-bot-update` раз в минуту проверяет GitHub и при новых коммитах сам обновляет и перезапускает бота.
Принудительно вручную: `bash update.sh`
Логи бота: `journalctl -u rust-bot -f`
Логи автообновления: `journalctl -u rust-bot-update -f`
